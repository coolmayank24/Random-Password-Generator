# 🔑 Random Password Generator

This is a simple, yet robust, **Random Password Generator** built using **HTML**, **CSS**, and **JavaScript**. This project allows users to generate strong, secure passwords based on their specified criteria, such as length and character types. 

***

## ✨ Features

- **Customizable Length**: Choose the desired length of your password.
- **Character Options**: Include or exclude a variety of character types:
    - **Uppercase** letters (A-Z)
    - **Lowercase** letters (a-z)
    - **Numbers** (0-9)
    - **Symbols** (!@#$%)
- **One-Click Generation**: Easily generate a new password with a single click.
- **Copy to Clipboard**: A convenient button to instantly copy the generated password.
- **User-Friendly Interface**: A clean and intuitive design for a seamless user experience.

***

## 🚀 How to Use

1. **Clone the repository**: `git clone https://github.com/coolmayank24/Random-Password-Generator.git`
2. **Open `index.html`**: Simply open the `index.html` file in your preferred web browser.
3. **Customize your password**: Use the sliders and checkboxes to select your desired password length and character types.
4. **Generate**: Click the "Generate Password" button to create a new password.
5. **Copy**: Click the "Copy" button to save the password to your clipboard.

***

## 🛠️ Technologies Used

- **HTML5**: For the basic structure and content of the web page.
- **CSS3**: For styling and creating a visually appealing interface.
- **JavaScript (ES6+)**: For the core logic of generating and handling the passwords.
